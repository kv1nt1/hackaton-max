# Сертификаты Минцифры

MAX требует доверять корневому сертификату Минцифры. Положи сюда два
файла (формат .crt / .cer / .pem) — бот подхватит их сам:

- `russian_trusted_root_ca_pem.crt` — корневой
- `russian_trusted_sub_ca_pem.crt` — промежуточный

Скачать: https://www.gosuslugi.ru/crt

Сертификаты публичные, их можно коммитить в репозиторий, чтобы у всей
команды всё работало сразу.
