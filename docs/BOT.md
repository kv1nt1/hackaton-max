# Как работает бот

## Старт

`/start` показывает выбор режима:

- **🏠 Создать комнату** — для компании, где каждый сам вводит свои данные;
- **🎯 Выбрать самостоятельно** — один человек вводит всё за всех.

## Режим «Комната»

1. Организатор создаёт комнату и заполняет свою анкету: интересы, бюджет,
   район, транспорт, сколько минут готов ехать.
2. Бот присылает ссылку-приглашение и код (`/join КОД`).
3. Каждый участник заполняет такую же анкету сам.
4. Организатор нажимает «Найти место». Результат получают все.

Организатор может менять **общие условия** комнаты («⚙️ Общие условия»:
исключённые категории, помещение/улица, еда, шум), не пересоздавая её.
Каждый участник может обновить свои данные («✏️ Мои данные»).

## Режим «Самостоятельно»

1. Пользователь отвечает на общие вопросы: бюджет, интересы, исключённые
   категории, помещение/улица, еда, шум.
2. Выбирает количество человек.
3. По очереди вводит данные каждого участника: район, транспорт, лимит
   времени в пути.
4. Получает результат. Комната не создаётся.

## Подбор мест

1. **Жёсткие условия** не смягчаются: место вмещает компанию, категория не
   исключена, цена не выше бюджета больше чем на 50%. Бюджет компании —
   **минимальный** из бюджетов участников.
2. **Интересы.** Считается, сколько участников отметили каждый интерес
   («Кофе (3 из 3)»). Чем больше людей разделяют интересы места, тем выше
   оно в списке. Место без единого совпадения получает штраф.
3. **Дорога** каждого участника считается по графу города (`app/core/routing.py`).
4. **Мягкие условия** (помещение/улица, еда, шум, бюджет в пределах допуска,
   время в пути до +50% к лимиту) дают штрафы. Если идеальных мест нет,
   показываются ближайшие с пометкой, что именно не совпало.

Сортировка: штраф → интерес-балл → максимальное время в пути
(справедливость) → среднее время → рейтинг. Веса штрафов — в
`app/core/filters.py` и `app/core/recommend.py`.

## Ограничения

- Комнаты и диалоги хранятся в памяти; максимум 10 участников; комната без
  активности удаляется через 48 часов.
- Местоположение участника — район города (представительная точка), а не
  точный адрес.
- Свободные дни и часы участников появятся после обновления БД.
- Используется long polling. Для продакшена MAX рекомендует webhook.
